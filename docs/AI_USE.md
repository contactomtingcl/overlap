# Use of Artificial Intelligence

## In the product

Overlap does not use AI inside the application. The harmonization is a statistical model whose error is measured on hidden years.

## During development

We used Claude (Anthropic) as an assistant to:

- write and review Python scripts for data auditing, cleaning and figures;
- draft and translate English text (README, documentation and submission fields);
- review the statistical method and point out risks.

All methods, decisions and results were defined, checked and run by the team. Files written with AI assistance carry a header line saying so.

We did not use AI-generated images, video or audio. No NASA logos or mission identifiers appear in any generated content.
